**Security Policy**

## 1. Purpose
This policy outlines essential security controls to protect enterprise information assets and ensure business continuity. **All employees** are responsible for adhering to these guidelines.

## 2. Access Control
*   **Unique Accounts:** All users must have unique, company-issued accounts. Sharing credentials is strictly prohibited.
*   **Strong Passwords:** Passwords must meet minimum complexity requirements (e.g., 12 characters, mix of uppercase, lowercase, numbers, symbols) and be changed every 90 days.
*   **Least Privilege:** Access to systems and data will be granted only to the extent necessary to perform job functions. Access requests require manager approval.
*   **Multi-Factor Authentication (MFA):** MFA is mandatory for all remote access and critical systems.

## 3. Data Protection
*   **Data Classification:** All data must be classified (e.g., Public, Internal, Confidential) and handled according to its classification.
*   **Encryption:** Sensitive data (e.g., customer PII, financial records) must be encrypted at rest and in transit.
*   **Backups:** Critical data must be regularly backed up to secure, offsite locations with tested recovery procedures.

## 4. Incident Response
*   **Reporting:** Any suspected security incident (e.g., data breach, malware infection, unauthorized access) must be immediately reported to IT Security.
*   **No Self-Remediation:** Employees must not attempt to resolve security incidents independently.

## 5. Employee Responsibilities
*   **Training:** All employees must complete annual security awareness training.
*   **Device Security:** Company-issued devices must be kept up-to-date with security patches and anti-malware software. Personal devices are not permitted for company work unless explicitly approved and secured.
*   **Clean Desk Policy:** Sensitive documents and equipment should not be left unattended.
